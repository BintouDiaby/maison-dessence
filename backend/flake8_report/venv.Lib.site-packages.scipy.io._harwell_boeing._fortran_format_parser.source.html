99 """Given a float number, returns a "reasonable" ExpFormat instance to
100 represent any number between -n and n.
101  
102 Parameters
103 ----------
104 n : float
105 max number one wants to be able to represent
106 min : int
107 minimum number of characters to use for the format
108  
109 Returns
110 -------
111 res : ExpFormat
112 ExpFormat instance with reasonable (see Notes) computed width
113  
114 Notes
115 -----
116 Reasonable should be understood as the minimal string length necessary
117 to avoid losing precision.
118 """
119 # len of one number in exp format: sign + 1|0 + "." +
120 # number of digit for fractional part + 'E' + sign of exponent +
121 # len of exponent
122 finfo = np.finfo(n.dtype)
123 # Number of digits for fractional part
124 n_prec = finfo.precision + 1
125 # Number of digits for exponential part
126 n_exp = number_digits(np.max(np.abs([finfo.maxexp, finfo.minexp])))
127 width = 1 + 1 + n_prec + 1 + n_exp + 1
128 if n < 0:
129 width += 1
130 repeat = int(np.floor(80 / width))
131 return cls(width, n_prec, min, repeat=repeat)

210 # format : LPAR format_string RPAR
211 # format_string : repeated | simple
