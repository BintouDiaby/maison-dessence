90  
91 Note on architecture
92 ======================
93  
94 There are three sets of parameters relevant for reading files. The
95 first are *file read parameters* - containing options that are common
96 for reading the whole file, and therefore every variable within that
97 file. At the moment these are:
98  
99 * mat_stream
100 * dtypes (derived from byte code)
101 * byte_order
102 * chars_as_strings
103 * squeeze_me
104 * struct_as_record (MATLAB 5 files)
105 * class_dtypes (derived from order code, MATLAB 5 files)
106 * codecs (MATLAB 5 files)
107 * uint16_codec (MATLAB 5 files)
108  
109 Another set of parameters are those that apply only to the current
110 variable being read - the *header*:
111  
112 * header related variables (different for v4 and v5 mat files)
113 * is_complex
114 * mclass
115 * var_stream
116  
117 With the header, we need ``next_position`` to tell us where the next
118 variable in the stream is.
119  
120 Then, for each element in a matrix, there can be *element read
121 parameters*. An element is, for example, one element in a MATLAB cell
122 array. At the moment, these are:
123  
124 * mat_dtype
125  
126 The file-reading object contains the *file read parameters*. The
127 *header* is passed around as a data object, or may be read and discarded
128 in a single function. The *element read parameters* - the mat_dtype in
129 this instance, is passed into a general post-processing function - see
130 ``mio_utils`` for details.

134 def convert_dtypes(dtype_template, order_code):
135 ''' Convert dtypes in mapping to given order
136  
137 Parameters
138 ----------
139 dtype_template : mapping
140 mapping with values returning numpy dtype from ``np.dtype(val)``
141 order_code : str
142 an order code suitable for using in ``dtype.newbyteorder()``
143  
144 Returns
145 -------
146 dtypes : mapping
147 mapping where values have been replaced by
148 ``np.dtype(val).newbyteorder(order_code)``
149  
150 '''
151 dtypes = dtype_template.copy()
152 for k in dtypes:
153 dtypes[k] = np.dtype(dtypes[k]).newbyteorder(order_code)

233 fileobj.seek(0)

238 raise MatReadError("Mat file appears to be corrupt "
239 f"(first {_HDR_N_BYTES} bytes == 0)")

243 return (0,0)
244 # For 5 format or 7.3 format we need to read an integer in the
245 # header. Bytes 124 through 128 contain a version integer and an
246 # endian test string
247 fileobj.seek(124)
248 tst_str = fileobj.read(4)
249 fileobj.seek(0)

259 def matdims(arr, oned_as='column'):
260 """
261 Determine equivalent MATLAB dimensions for given array
262  
263 Parameters
264 ----------
265 arr : ndarray
266 Input array
267 oned_as : {'column', 'row'}, optional
268 Whether 1-D arrays are returned as MATLAB row or column matrices.
269 Default is 'column'.
270  
271 Returns
272 -------
273 dims : tuple
274 Shape tuple, in the form MATLAB expects it.
275  
276 Notes
277 -----
278 We had to decide what shape a 1 dimensional array would be by
279 default. ``np.atleast_2d`` thinks it is a row vector. The
280 default for a vector in MATLAB (e.g., ``>> 1:12``) is a row vector.
281  
282 Versions of scipy up to and including 0.11 resulted (accidentally)
283 in 1-D arrays being read as column vectors. For the moment, we
284 maintain the same tradition here.
285  
286 Examples
287 --------
288 >>> import numpy as np
289 >>> from scipy.io.matlab._miobase import matdims
290 >>> matdims(np.array(1)) # NumPy scalar
291 (1, 1)
292 >>> matdims(np.array([1])) # 1-D array, 1 element
293 (1, 1)
294 >>> matdims(np.array([1,2])) # 1-D array, 2 elements
295 (2, 1)
296 >>> matdims(np.array([[2],[3]])) # 2-D array, column vector
297 (2, 1)
298 >>> matdims(np.array([[2,3]])) # 2-D array, row vector
299 (1, 2)
300 >>> matdims(np.array([[[2,3]]])) # 3-D array, rowish vector
301 (1, 1, 2)
302 >>> matdims(np.array([])) # empty 1-D array
303 (0, 0)
304 >>> matdims(np.array([[]])) # empty 2-D array
305 (0, 0)
306 >>> matdims(np.array([[[]]])) # empty 3-D array
307 (0, 0, 0)
308  
309 Optional argument flips 1-D shape behavior.
310  
311 >>> matdims(np.array([1,2]), 'row') # 1-D array, 2 elements
312 (1, 2)
313  
314 The argument has to make sense though
315  
316 >>> matdims(np.array([1,2]), 'bizarre')
317 Traceback (most recent call last):
318 ...
319 ValueError: 1-D option "bizarre" is strange
320  
321 """
322 shape = arr.shape
323 if shape == (): # scalar
324 return (1, 1)
325 if len(shape) == 1: # 1D
326 if shape[0] == 0:
327 return (0, 0)
328 elif oned_as == 'column':
329 return shape + (1,)
330 elif oned_as == 'row':
331 return (1,) + shape
332 else:
333 raise ValueError(f'1-D option "{oned_as}" is strange')
334 return shape

421 def arr_to_chars(arr):
422 ''' Convert string array to char array '''
423 dims = list(arr.shape)
424 if not dims:
425 dims = [1]
426 dims.append(int(arr.dtype.str[2:]))
427 arr = np.ndarray(shape=dims,
428 dtype=arr_dtype_number(arr, 1),
429 buffer=arr)
430 empties = [arr == np.array('', dtype=arr.dtype)]
431 if not np.any(empties):
432 return arr
433 arr = arr.copy()
434 arr[tuple(empties)] = ' '
