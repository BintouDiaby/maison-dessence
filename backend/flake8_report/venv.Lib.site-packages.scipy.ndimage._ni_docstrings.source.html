24 """size : scalar or tuple, optional
25 See footprint, below. Ignored if footprint is given.
26 footprint : array, optional
27 Either `size` or `footprint` must be defined. `size` gives
28 the shape that is taken from the input array, at every element
29 position, to define the input to the filter function.
30 `footprint` is a boolean array that specifies (implicitly) a
31 shape, but also which of the elements within this shape will get
32 passed to the filter function. Thus ``size=(n,m)`` is equivalent
33 to ``footprint=np.ones((n,m))``. We adjust `size` to the number
34 of dimensions of the input array, so that, if the input array is
35 shape (10,10,10), and `size` is 2, then the actual size used is
36 (2,2,2). When `footprint` is given, `size` is ignored.""")
