15 SciPy 2-D sparse array package for numeric data.
16  
17 .. note::
18  
19 This package is switching to an array interface, compatible with
20 NumPy arrays, from the older matrix interface. We recommend that
21 you use the array objects (`bsr_array`, `coo_array`, etc.) for
22 all new work.
23  
24 When using the array interface, please note that:
25  
26 - ``x * y`` no longer performs matrix multiplication, but
27 element-wise multiplication (just like with NumPy arrays). To
28 make code work with both arrays and matrices, use ``x @ y`` for
29 matrix multiplication.
30 - Operations such as ``sum``, that used to produce dense matrices, now
31 produce arrays, whose multiplication behavior differs similarly.
32 - Sparse arrays use array style *slicing* operations, returning scalars,
33 1D, or 2D sparse arrays. If you need 2D results, use an appropriate index.
34 E.g. ``A[:, i, None]`` or ``A[:, [i]]``.
35 - All index arrays for a given sparse array should be of same dtype.
36 For example, for CSR format, ``indices`` and ``indptr`` should have
37 the same dtype. For COO, each array in `coords` should have same dtype.
38  
39 The construction utilities (`eye`, `kron`, `random`, `diags`, etc.)
40 have appropriate replacements (see :ref:`sparse-construction-functions`).
41  
42 For more information see
43 :ref:`Migration from spmatrix to sparray <migration_to_sparray>`.

178 Usage information
179 =================
180  
181 There are seven available sparse array types:
182  
183 1. csc_array: Compressed Sparse Column format
184 2. csr_array: Compressed Sparse Row format
185 3. bsr_array: Block Sparse Row format
186 4. lil_array: List of Lists format
187 5. dok_array: Dictionary of Keys format
188 6. coo_array: COOrdinate format (aka IJV, triplet format)
189 7. dia_array: DIAgonal format
190  
191 To construct an array efficiently, use any of `coo_array`,
192 `dok_array` or `lil_array`. `dok_array` and `lil_array`
193 support basic slicing and fancy indexing with a similar syntax
194 to NumPy arrays. The COO format does not support indexing (yet)
195 but can also be used to efficiently construct arrays using coord
196 and value info.
197  
198 Despite their similarity to NumPy arrays, it is **strongly discouraged**
199 to use NumPy functions directly on these arrays because NumPy typically
200 treats them as generic Python objects rather than arrays, leading to
201 unexpected (and incorrect) results. If you do want to apply a NumPy
202 function to these arrays, first check if SciPy has its own implementation
203 for the given sparse array class, or **convert the sparse array to
204 a NumPy array** (e.g., using the `toarray` method of the class)
205 before applying the method.
206  
207 All conversions among the CSR, CSC, and COO formats are efficient,
208 linear-time operations.
209  
210 To perform manipulations such as multiplication or inversion, first
211 convert the array to either CSC or CSR format. The `lil_array`
212 format is row-based, so conversion to CSR is efficient, whereas
213 conversion to CSC is less so.
214  
215 Matrix vector product
216 ---------------------
217  
218 To do a vector product between a 2D sparse array and a vector use
219 the matmul operator (i.e., ``@``) which performs a dot product (like the
220 ``dot`` method):
221  
222 >>> import numpy as np
223 >>> from scipy.sparse import csr_array
224 >>> A = csr_array([[1, 2, 0], [0, 0, 3], [4, 0, 5]])
225 >>> v = np.array([1, 0, -1])
226 >>> A @ v
227 array([ 1, -3, -1], dtype=int64)
228  
229 The CSR format is especially suitable for fast matrix vector products.
230  
231 Example 1
232 ---------
233  
234 Construct a 1000x1000 `lil_array` and add some values to it:
235  
236 >>> from scipy.sparse import lil_array
237 >>> from scipy.sparse.linalg import spsolve
238 >>> from numpy.linalg import solve, norm
239 >>> from numpy.random import rand
240  
241 >>> A = lil_array((1000, 1000))
242 >>> A[0, :100] = rand(100)
243 >>> A.setdiag(rand(1000))
244  
245 Now convert it to CSR format and solve A x = b for x:
246  
247 >>> A = A.tocsr()
248 >>> b = rand(1000)
249 >>> x = spsolve(A, b)
250  
251 Convert it to a dense array and solve, and check that the result
252 is the same:
253  
254 >>> x_ = solve(A.toarray(), b)
255  
256 Now we can compute norm of the error with:
257  
258 >>> err = norm(x-x_)
259 >>> err < 1e-9
260 True
261  
262 It should be small :)
263  
264  
265 Example 2
266 ---------
267  
268 Construct an array in COO format:
269  
270 >>> from scipy import sparse
271 >>> from numpy import array
272 >>> I = array([0,3,1,0])
273 >>> J = array([0,3,1,2])
274 >>> V = array([4,5,7,9])
275 >>> A = sparse.coo_array((V,(I,J)),shape=(4,4))
276  
277 Notice that the indices do not need to be sorted.
278  
279 Duplicate (i,j) entries are summed when converting to CSR or CSC.
280  
281 >>> I = array([0,0,1,3,1,0,0])
282 >>> J = array([0,2,1,3,1,0,0])
283 >>> V = array([1,1,1,1,1,1,1])
284 >>> B = sparse.coo_array((V,(I,J)),shape=(4,4)).tocsr()
285  
286 This is useful for constructing finite-element stiffness and mass matrices.
287  
288 Further details
289 ---------------
290  
291 CSR column indices are not necessarily sorted. Likewise for CSC row
292 indices. Use the ``.sorted_indices()`` and ``.sort_indices()`` methods when
293 sorted indices are required (e.g., when passing data to other libraries).
