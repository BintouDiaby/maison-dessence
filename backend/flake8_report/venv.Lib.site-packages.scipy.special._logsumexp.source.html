257 @xp_capabilities()
258 def softmax(x, axis=None):
259 r"""Compute the softmax function.
260  
261 The softmax function transforms each element of a collection by
262 computing the exponential of each element divided by the sum of the
263 exponentials of all the elements. That is, if `x` is a one-dimensional
264 numpy array::
265  
266 softmax(x) = np.exp(x)/sum(np.exp(x))
267  
268 Parameters
269 ----------
270 x : array_like
271 Input array.
272 axis : int or tuple of ints, optional
273 Axis to compute values along. Default is None and softmax will be
274 computed over the entire array `x`.
275  
276 Returns
277 -------
278 s : ndarray
279 An array the same shape as `x`. The result will sum to 1 along the
280 specified axis.
281  
282 Notes
283 -----
284 The formula for the softmax function :math:`\sigma(x)` for a vector
285 :math:`x = \{x_0, x_1, ..., x_{n-1}\}` is
286  
287 .. math:: \sigma(x)_j = \frac{e^{x_j}}{\sum_k e^{x_k}}
288  
289 The `softmax` function is the gradient of `logsumexp`.
290  
291 The implementation uses shifting to avoid overflow. See [1]_ for more
292 details.
293  
294 .. versionadded:: 1.2.0
295  
296 References
297 ----------
298 .. [1] P. Blanchard, D.J. Higham, N.J. Higham, "Accurately computing the
299 log-sum-exp and softmax functions", IMA Journal of Numerical Analysis,
300 Vol.41(4), :doi:`10.1093/imanum/draa038`.
301  
302 Examples
303 --------

306 >>> np.set_printoptions(precision=5)
307

320  
321 >>> m.sum()

323

326
