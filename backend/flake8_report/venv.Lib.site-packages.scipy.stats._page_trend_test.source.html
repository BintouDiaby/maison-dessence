19 def page_trend_test(data, ranked=False, predicted_ranks=None, method='auto'):
20 r"""
21 Perform Page's Test, a measure of trend in observations between treatments.
22  
23 Page's Test (also known as Page's :math:`L` test) is useful when:
24  
25 * there are :math:`n \geq 3` treatments,
26 * :math:`m \geq 2` subjects are observed for each treatment, and
27 * the observations are hypothesized to have a particular order.
28  
29 Specifically, the test considers the null hypothesis that
30  
31 .. math::
32  
33 m_1 = m_2 = m_3 \cdots = m_n,
34  
35 where :math:`m_j` is the mean of the observed quantity under treatment
36 :math:`j`, against the alternative hypothesis that
37  
38 .. math::
39  
40 m_1 \leq m_2 \leq m_3 \leq \cdots \leq m_n,
41  
42 where at least one inequality is strict.
43  
44 As noted by [4]_, Page's :math:`L` test has greater statistical power than
45 the Friedman test against the alternative that there is a difference in
46 trend, as Friedman's test only considers a difference in the means of the
47 observations without considering their order. Whereas Spearman :math:`\rho`
48 considers the correlation between the ranked observations of two variables
49 (e.g. the airspeed velocity of a swallow vs. the weight of the coconut it
50 carries), Page's :math:`L` is concerned with a trend in an observation
51 (e.g. the airspeed velocity of a swallow) across several distinct
52 treatments (e.g. carrying each of five coconuts of different weight) even
53 as the observation is repeated with multiple subjects (e.g. one European
54 swallow and one African swallow).
55  
56 Parameters
57 ----------
58 data : array-like
59 A :math:`m \times n` array; the element in row :math:`i` and
60 column :math:`j` is the observation corresponding with subject
61 :math:`i` and treatment :math:`j`. By default, the columns are
62 assumed to be arranged in order of increasing predicted mean.
63  
64 ranked : boolean, optional
65 By default, `data` is assumed to be observations rather than ranks;
66 it will be ranked with `scipy.stats.rankdata` along ``axis=1``. If
67 `data` is provided in the form of ranks, pass argument ``True``.
68  
69 predicted_ranks : array-like, optional
70 The predicted ranks of the column means. If not specified,
71 the columns are assumed to be arranged in order of increasing
72 predicted mean, so the default `predicted_ranks` are
73 :math:`[1, 2, \dots, n-1, n]`.
74  
75 method : {'auto', 'asymptotic', 'exact'}, optional
76 Selects the method used to calculate the *p*-value. The following
77 options are available.
78  
79 * 'auto': selects between 'exact' and 'asymptotic' to
80 achieve reasonably accurate results in reasonable time (default)
81 * 'asymptotic': compares the standardized test statistic against
82 the normal distribution
83 * 'exact': computes the exact *p*-value by comparing the observed
84 :math:`L` statistic against those realized by all possible
85 permutations of ranks (under the null hypothesis that each
86 permutation is equally likely)
87  
88 Returns
89 -------
90 res : PageTrendTestResult
91 An object containing attributes:
92  
93 statistic : float
94 Page's :math:`L` test statistic.
95 pvalue : float
96 The associated *p*-value
97 method : {'asymptotic', 'exact'}
98 The method used to compute the *p*-value

104 Notes
105 -----
106 As noted in [1]_, "the :math:`n` 'treatments' could just as well represent
107 :math:`n` objects or events or performances or persons or trials ranked."
108 Similarly, the :math:`m` 'subjects' could equally stand for :math:`m`
109 "groupings by ability or some other control variable, or judges doing
110 the ranking, or random replications of some other sort."
111  
112 The procedure for calculating the :math:`L` statistic, adapted from
113 [1]_, is:
114  
115 1. "Predetermine with careful logic the appropriate hypotheses
116 concerning the predicted ordering of the experimental results.
117 If no reasonable basis for ordering any treatments is known, the
118 :math:`L` test is not appropriate."
119 2. "As in other experiments, determine at what level of confidence
120 you will reject the null hypothesis that there is no agreement of
121 experimental results with the monotonic hypothesis."
122 3. "Cast the experimental material into a two-way table of :math:`n`
123 columns (treatments, objects ranked, conditions) and :math:`m`
124 rows (subjects, replication groups, levels of control variables)."
125 4. "When experimental observations are recorded, rank them across each
126 row", e.g. ``ranks = scipy.stats.rankdata(data, axis=1)``.
127 5. "Add the ranks in each column", e.g.
128 ``colsums = np.sum(ranks, axis=0)``.
129 6. "Multiply each sum of ranks by the predicted rank for that same
130 column", e.g. ``products = predicted_ranks * colsums``.
131 7. "Sum all such products", e.g. ``L = products.sum()``.
132  
133 [1]_ continues by suggesting use of the standardized statistic
134  
135 .. math::
136  
137 \chi_L^2 = \frac{\left[12L-3mn(n+1)^2\right]^2}{mn^2(n^2-1)(n+1)}
138  
139 "which is distributed approximately as chi-square with 1 degree of
140 freedom. The ordinary use of :math:`\chi^2` tables would be
141 equivalent to a two-sided test of agreement. If a one-sided test
142 is desired, *as will almost always be the case*, the probability
143 discovered in the chi-square table should be *halved*."
144  
145 However, this standardized statistic does not distinguish between the
146 observed values being well correlated with the predicted ranks and being
147 _anti_-correlated with the predicted ranks. Instead, we follow [2]_
148 and calculate the standardized statistic
149  
150 .. math::
151  
152 \Lambda = \frac{L - E_0}{\sqrt{V_0}},
153  
154 where :math:`E_0 = \frac{1}{4} mn(n+1)^2` and
155 :math:`V_0 = \frac{1}{144} mn^2(n+1)(n^2-1)`, "which is asymptotically
156 normal under the null hypothesis".
157  
158 The *p*-value for ``method='exact'`` is generated by comparing the observed
159 value of :math:`L` against the :math:`L` values generated for all
160 :math:`(n!)^m` possible permutations of ranks. The calculation is performed
161 using the recursive method of [5].
162  
163 The *p*-values are not adjusted for the possibility of ties. When
164 ties are present, the reported ``'exact'`` *p*-values may be somewhat
165 larger (i.e. more conservative) than the true *p*-value [2]_. The
166 ``'asymptotic'``` *p*-values, however, tend to be smaller (i.e. less
167 conservative) than the ``'exact'`` *p*-values.

190 Examples
191 --------
192 We use the example from [3]_: 10 students are asked to rate three
193 teaching methods - tutorial, lecture, and seminar - on a scale of 1-5,
194 with 1 being the lowest and 5 being the highest. We have decided that
195 a confidence level of 99% is required to reject the null hypothesis in
196 favor of our alternative: that the seminar will have the highest ratings
197 and the tutorial will have the lowest. Initially, the data have been
198 tabulated with each row representing an individual student's ratings of
199 the three methods in the following order: tutorial, lecture, seminar.
200  
201 >>> table = [[3, 4, 3],
202 ... [2, 2, 4],
203 ... [3, 3, 5],
204 ... [1, 3, 2],
205 ... [2, 3, 2],
206 ... [2, 4, 5],
207 ... [1, 2, 4],
208 ... [3, 4, 4],
209 ... [2, 4, 5],
210 ... [1, 3, 4]]
211  
212 Because the tutorial is hypothesized to have the lowest ratings, the
213 column corresponding with tutorial rankings should be first; the seminar
214 is hypothesized to have the highest ratings, so its column should be last.
215 Since the columns are already arranged in this order of increasing
216 predicted mean, we can pass the table directly into `page_trend_test`.
217  
218 >>> from scipy.stats import page_trend_test
219 >>> res = page_trend_test(table)
220 >>> res
221 PageTrendTestResult(statistic=133.5, pvalue=0.0018191161948127822,
222 method='exact')
223  
224 This *p*-value indicates that there is a 0.1819% chance that
225 the :math:`L` statistic would reach such an extreme value under the null
226 hypothesis. Because 0.1819% is less than 1%, we have evidence to reject
227 the null hypothesis in favor of our alternative at a 99% confidence level.
228  
229 The value of the :math:`L` statistic is 133.5. To check this manually,
230 we rank the data such that high scores correspond with high ranks, settling
231 ties with an average rank:
232  
233 >>> from scipy.stats import rankdata
234 >>> ranks = rankdata(table, axis=1)
235 >>> ranks
236 array([[1.5, 3. , 1.5],
237 [1.5, 1.5, 3. ],
238 [1.5, 1.5, 3. ],
239 [1. , 3. , 2. ],
240 [1.5, 3. , 1.5],
241 [1. , 2. , 3. ],
242 [1. , 2. , 3. ],
243 [1. , 2.5, 2.5],
244 [1. , 2. , 3. ],
245 [1. , 2. , 3. ]])
246  
247 We add the ranks within each column, multiply the sums by the
248 predicted ranks, and sum the products.
249  
250 >>> import numpy as np
251 >>> m, n = ranks.shape
252 >>> predicted_ranks = np.arange(1, n+1)
253 >>> L = (predicted_ranks * np.sum(ranks, axis=0)).sum()
254 >>> res.statistic == L
255 True
256  
257 As presented in [3]_, the asymptotic approximation of the *p*-value is the
258 survival function of the normal distribution evaluated at the standardized
259 test statistic:
260  
261 >>> from scipy.stats import norm
262 >>> E0 = (m*n*(n+1)**2)/4
263 >>> V0 = (m*n**2*(n+1)*(n**2-1))/144
264 >>> Lambda = (L-E0)/np.sqrt(V0)
265 >>> p = norm.sf(Lambda)
266 >>> p
267 0.0012693433690751756
268  
269 This does not precisely match the *p*-value reported by `page_trend_test`
270 above. The asymptotic distribution is not very accurate, nor conservative,
271 for :math:`m \leq 12` and :math:`n \leq 8`, so `page_trend_test` chose to
272 use ``method='exact'`` based on the dimensions of the table and the
273 recommendations in Page's original paper [1]_. To override
274 `page_trend_test`'s choice, provide the `method` argument.
275  
276 >>> res = page_trend_test(table, method="asymptotic")
277 >>> res
278 PageTrendTestResult(statistic=133.5, pvalue=0.0012693433690751756,
279 method='asymptotic')
280  
281 If the data are already ranked, we can pass in the ``ranks`` instead of
282 the ``table`` to save computation time.
283  
284 >>> res = page_trend_test(ranks, # ranks of data
285 ... ranked=True, # data is already ranked
286 ... )
287 >>> res
288 PageTrendTestResult(statistic=133.5, pvalue=0.0018191161948127822,
289 method='exact')
290  
291 Suppose the raw data had been tabulated in an order different from the
292 order of predicted means, say lecture, seminar, tutorial.
293  
294 >>> table = np.asarray(table)[:, [1, 2, 0]]
295  
296 Since the arrangement of this table is not consistent with the assumed
297 ordering, we can either rearrange the table or provide the
298 `predicted_ranks`. Remembering that the lecture is predicted
299 to have the middle rank, the seminar the highest, and tutorial the lowest,
300 we pass:
301  
302 >>> res = page_trend_test(table, # data as originally tabulated
303 ... predicted_ranks=[2, 3, 1], # our predicted order
304 ... )
305 >>> res
306 PageTrendTestResult(statistic=133.5, pvalue=0.0018191161948127822,
307 method='exact')

372 def _choose_method(ranks):
373 '''Choose method for computing p-value automatically'''
374 m, n = ranks.shape
375 if n > 8 or (m > 12 and n > 3) or m > 20: # as in [1], [4]

377 else:

382 def _l_vectorized(ranks, predicted_ranks):
383 '''Calculate's Page's L statistic for each page of a 3d array'''
384 colsums = ranks.sum(axis=-2, keepdims=True)
385 products = predicted_ranks * colsums
386 Ls = products.sum(axis=-1)
387 Ls = Ls[0] if Ls.size == 1 else Ls.ravel()
388 return Ls

391 def _l_p_asymptotic(L, m, n):
392 '''Calculate the p-value of Page's L from the asymptotic distribution'''
393 # Using [1] as a reference, the asymptotic p-value would be calculated as:
394 # chi_L = (12*L - 3*m*n*(n+1)**2)**2/(m*n**2*(n**2-1)*(n+1))
395 # p = chi2.sf(chi_L, df=1, loc=0, scale=1)/2
396 # but this is insensitive to the direction of the hypothesized ranking
397  
398 # See [2] page 151
399 E0 = (m*n*(n+1)**2)/4
400 V0 = (m*n**2*(n+1)*(n**2-1))/144
401 Lambda = (L-E0)/np.sqrt(V0)
402 # This is a one-sided "greater" test - calculate the probability that the
403 # L statistic under H0 would be greater than the observed L statistic
404 p = norm.sf(Lambda)
405 return p

408 def _l_p_exact(L, m, n):
409 '''Calculate the p-value of Page's L exactly'''
410 # [1] uses m, n; [5] uses n, k.
411 # Switch convention here because exact calculation code references [5].
412 L, n, k = int(L), int(m), int(n)
413 _pagel_state.state.set_k(k)
414 return _pagel_state.state.sf(L, n)
