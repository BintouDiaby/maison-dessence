419 class HDBSCAN(ClusterMixin, BaseEstimator):
420 """Cluster data using hierarchical density-based clustering.
421  
422 HDBSCAN - Hierarchical Density-Based Spatial Clustering of Applications
423 with Noise. Performs :class:`~sklearn.cluster.DBSCAN` over varying epsilon
424 values and integrates the result to find a clustering that gives the best
425 stability over epsilon.
426 This allows HDBSCAN to find clusters of varying densities (unlike
  • E501 Line too long (81 > 79 characters)
427 :class:`~sklearn.cluster.DBSCAN`), and be more robust to parameter selection.
428 Read more in the :ref:`User Guide <hdbscan>`.
429  
430 .. versionadded:: 1.3
431

434 min_cluster_size : int, default=5
435 The minimum number of samples in a group for that group to be

438  
439 min_samples : int, default=None
440 The parameter `k` used to calculate the distance between a point
441 `x_p` and its k-th nearest neighbor.
442 When `None`, defaults to `min_cluster_size`.
443  
444 cluster_selection_epsilon : float, default=0.0
445 A distance threshold. Clusters below this value will be merged.
446 See [5]_ for more information.
447  
448 max_cluster_size : int, default=None
449 A limit to the size of clusters returned by the `"eom"` cluster
450 selection algorithm. There is no limit when `max_cluster_size=None`.
451 Has no effect if `cluster_selection_method="leaf"`.
452  
453 metric : str or callable, default='euclidean'
454 The metric to use when calculating distance between instances in a
455 feature array.
456  
457 - If metric is a string or callable, it must be one of
458 the options allowed by :func:`~sklearn.metrics.pairwise_distances`
459 for its metric parameter.

462 must be square.

465 Arguments passed to the distance metric.

467 alpha : float, default=1.0
468 A distance scaling parameter as used in robust single linkage.
469 See [3]_ for more information.
470  
471 algorithm : {"auto", "brute", "kd_tree", "ball_tree"}, default="auto"
472 Exactly which algorithm to use for computing core distances; By default
473 this is set to `"auto"` which attempts to use a
474 :class:`~sklearn.neighbors.KDTree` tree if possible, otherwise it uses
475 a :class:`~sklearn.neighbors.BallTree` tree. Both `"kd_tree"` and
476 `"ball_tree"` algorithms use the
477 :class:`~sklearn.neighbors.NearestNeighbors` estimator.
