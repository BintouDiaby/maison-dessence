861 Notes
862 -----
863 The search for the optimal penalization parameter (`alpha`) is done on an
864 iteratively refined grid: first the cross-validated scores on a grid are
865 computed, then a new refined grid is centered around the maximum, and so
866 on.
867  
868 One of the challenges which is faced here is that the solvers can
869 fail to converge to a well-conditioned estimate. The corresponding
870 values of `alpha` then come out as missing values, but the optimum may
871 be close to these missing values.
872  
873 In `fit`, once the best parameter `alpha` is found through
874 cross-validation, the model is fit again using the entire training set.
