2 Forest of trees-based ensemble methods.
3  
4 Those methods include random forests and extremely randomized trees.
5  
6 The module structure is the following:
7  
8 - The ``BaseForest`` base class implements a common ``fit`` method for all
9 the estimators in the module. The ``fit`` method of the base ``Forest``
10 class calls the ``fit`` method of each sub-estimator on random samples
11 (with replacement, a.k.a. bootstrap) of the training set.
12  
13 The init of the sub-estimator is further delegated to the
14 ``BaseEnsemble`` constructor.
15

17 implement the prediction logic by computing an average of the predicted
18 outcomes of the sub-estimators.
19  
20 - The ``RandomForestClassifier`` and ``RandomForestRegressor`` derived
21 classes provide the user with concrete implementations of
22 the forest ensemble method using classical, deterministic
23 ``DecisionTreeClassifier`` and ``DecisionTreeRegressor`` as
24 sub-estimator implementations.
25

27 classes provide the user with concrete implementations of the

2677 class RandomTreesEmbedding(TransformerMixin, BaseForest):
2678 """
2679 An ensemble of totally random trees.
2680  
2681 An unsupervised transformation of a dataset to a high-dimensional
2682 sparse representation. A datapoint is coded according to which leaf of
2683 each tree it is sorted into. Using a one-hot encoding of the leaves,
2684 this leads to a binary coding with as many ones as there are trees in
2685 the forest.
2686  
2687 The dimensionality of the resulting representation is
2688 ``n_out <= n_estimators * max_leaf_nodes``. If ``max_leaf_nodes == None``,
2689 the number of leaf nodes is at most ``n_estimators * 2 ** max_depth``.
2690  
2691 For an example of applying Random Trees Embedding to non-linear
2692 classification, see
2693 :ref:`sphx_glr_auto_examples_ensemble_plot_random_forest_embedding.py`.
2694  
2695 Read more in the :ref:`User Guide <random_trees_embedding>`.
2696  
2697 Parameters
2698 ----------
2699 n_estimators : int, default=100
2700 Number of trees in the forest.
2701  
2702 .. versionchanged:: 0.22
2703 The default value of ``n_estimators`` changed from 10 to 100
2704 in 0.22.
2705  
2706 max_depth : int, default=5
2707 The maximum depth of each tree. If None, then nodes are expanded until
2708 all leaves are pure or until all leaves contain less than
2709 min_samples_split samples.
2710  
2711 min_samples_split : int or float, default=2
2712 The minimum number of samples required to split an internal node:
2713  
2714 - If int, then consider `min_samples_split` as the minimum number.
2715 - If float, then `min_samples_split` is a fraction and
2716 `ceil(min_samples_split * n_samples)` is the minimum
2717 number of samples for each split.
2718  
2719 .. versionchanged:: 0.18
2720 Added float values for fractions.
2721  
2722 min_samples_leaf : int or float, default=1
2723 The minimum number of samples required to be at a leaf node.
2724 A split point at any depth will only be considered if it leaves at
2725 least ``min_samples_leaf`` training samples in each of the left and
2726 right branches. This may have the effect of smoothing the model,
2727 especially in regression.
2728  
2729 - If int, then consider `min_samples_leaf` as the minimum number.
2730 - If float, then `min_samples_leaf` is a fraction and
2731 `ceil(min_samples_leaf * n_samples)` is the minimum
2732 number of samples for each node.
2733  
2734 .. versionchanged:: 0.18
2735 Added float values for fractions.
2736  
2737 min_weight_fraction_leaf : float, default=0.0
2738 The minimum weighted fraction of the sum total of weights (of all
2739 the input samples) required to be at a leaf node. Samples have
2740 equal weight when sample_weight is not provided.
2741  
2742 max_leaf_nodes : int, default=None
2743 Grow trees with ``max_leaf_nodes`` in best-first fashion.
2744 Best nodes are defined as relative reduction in impurity.
2745 If None then unlimited number of leaf nodes.
2746  
2747 min_impurity_decrease : float, default=0.0
2748 A node will be split if this split induces a decrease of the impurity
2749 greater than or equal to this value.
2750  
2751 The weighted impurity decrease equation is the following::
2752  
2753 N_t / N * (impurity - N_t_R / N_t * right_impurity
2754 - N_t_L / N_t * left_impurity)
2755  
2756 where ``N`` is the total number of samples, ``N_t`` is the number of
2757 samples at the current node, ``N_t_L`` is the number of samples in the
2758 left child, and ``N_t_R`` is the number of samples in the right child.
2759  
2760 ``N``, ``N_t``, ``N_t_R`` and ``N_t_L`` all refer to the weighted sum,
2761 if ``sample_weight`` is passed.
2762  
2763 .. versionadded:: 0.19
2764  
2765 sparse_output : bool, default=True
2766 Whether or not to return a sparse CSR matrix, as default behavior,
2767 or to return a dense array compatible with dense pipeline operators.
2768  
2769 n_jobs : int, default=None
2770 The number of jobs to run in parallel. :meth:`fit`, :meth:`transform`,
2771 :meth:`decision_path` and :meth:`apply` are all parallelized over the
2772 trees. ``None`` means 1 unless in a :obj:`joblib.parallel_backend`
2773 context. ``-1`` means using all processors. See :term:`Glossary
2774 <n_jobs>` for more details.
2775  
2776 random_state : int, RandomState instance or None, default=None

2779 See :term:`Glossary <random_state>` for details.

2781 verbose : int, default=0

2783

2788 :ref:`tree_ensemble_warm_start` for details.
