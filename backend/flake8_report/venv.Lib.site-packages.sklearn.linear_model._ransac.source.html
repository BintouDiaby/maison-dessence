47 def _dynamic_max_trials(n_inliers, n_samples, min_samples, probability):
48 """Determine number trials such that at least one outlier-free subset is
49 sampled for the given inlier/outlier ratio.
50  
51 Parameters
52 ----------
53 n_inliers : int
54 Number of inliers in the data.
55  
56 n_samples : int
57 Total number of samples in the data.
58  
59 min_samples : int
60 Minimum number of samples chosen randomly from original data.
61  
62 probability : float
63 Probability (confidence) that one outlier-free sample is generated.
64  
65 Returns
66 -------
67 trials : int
68 Number of trials.
69  
70 """
71 inlier_ratio = n_inliers / float(n_samples)
72 nom = max(_EPSILON, 1 - probability)
73 denom = max(_EPSILON, 1 - inlier_ratio**min_samples)
74 if nom == 1:
75 return 0
76 if denom == 1:
77 return float("inf")
78 return abs(float(np.ceil(np.log(nom) / np.log(denom))))

87 """RANSAC (RANdom SAmple Consensus) algorithm.
88  
89 RANSAC is an iterative algorithm for the robust estimation of parameters
90 from a subset of inliers from the complete data set.
91  
92 Read more in the :ref:`User Guide <ransac_regression>`.
93  
94 Parameters
95 ----------
96 estimator : object, default=None
97 Base estimator object which implements the following methods:
98  
99 * `fit(X, y)`: Fit model to given training data and target values.
100 * `score(X, y)`: Returns the mean accuracy on the given test data,
101 which is used for the stop criterion defined by `stop_score`.
102 Additionally, the score is used to decide which of two equally
103 large consensus sets is chosen as the better one.
104 * `predict(X)`: Returns predicted values using the linear model,
105 which is used to compute residual error using loss function.
106  
107 If `estimator` is None, then
108 :class:`~sklearn.linear_model.LinearRegression` is used for
109 target values of dtype float.
110  
111 Note that the current implementation only supports regression
112 estimators.
113  
114 min_samples : int (>= 1) or float ([0, 1]), default=None
115 Minimum number of samples chosen randomly from original data. Treated
116 as an absolute number of samples for `min_samples >= 1`, treated as a
117 relative number `ceil(min_samples * X.shape[0])` for
118 `min_samples < 1`. This is typically chosen as the minimal number of
119 samples necessary to estimate the given `estimator`. By default a

130 strictly equal to the threshold are considered as inliers.

140 False the current randomly chosen sub-sample is skipped.

145 max_trials : int, default=100

153 .. versionadded:: 0.19
154  
155 stop_n_inliers : int, default=np.inf
156 Stop iteration if at least this number of inliers are found.
157  
158 stop_score : float, default=np.inf
159 Stop iteration if score is greater equal than this threshold.
160  
161 stop_probability : float in range [0, 1], default=0.99
162 RANSAC iteration stops if at least one outlier-free set of the training
163 data is sampled in RANSAC. This requires to generate at least N
164 samples (iterations)::
165  
166 N >= log(1 - probability) / log(1 - e**m)
167  
168 where the probability (confidence) is typically set to high value such

171
