38 def _joint_probabilities(distances, desired_perplexity, verbose):
39 """Compute joint probabilities p_ij from distances.
40  
41 Parameters
42 ----------
43 distances : ndarray of shape (n_samples * (n_samples-1) / 2,)
44 Distances of samples are stored as condensed matrices, i.e.
45 we omit the diagonal and duplicate entries and store everything
46 in a one-dimensional array.
47  
48 desired_perplexity : float
49 Desired perplexity of the joint probability distributions.
50  
51 verbose : int
52 Verbosity level.
53  
54 Returns
55 -------
56 P : ndarray of shape (n_samples * (n_samples-1) / 2,)
57 Condensed joint probability matrix.
58 """
59 # Compute conditional probabilities such that they approximately match
60 # the desired perplexity
61 distances = distances.astype(np.float32, copy=False)
62 conditional_P = _utils._binary_search_perplexity(
63 distances, desired_perplexity, verbose
64 )
65 P = conditional_P + conditional_P.T
66 sum_P = np.maximum(np.sum(P), MACHINE_EPSILON)
67 P = np.maximum(squareform(P) / sum_P, MACHINE_EPSILON)
68 return P

560 class TSNE(ClassNamePrefixFeaturesOutMixin, TransformerMixin, BaseEstimator):
561 """T-distributed Stochastic Neighbor Embedding.
562  
563 t-SNE [1] is a tool to visualize high-dimensional data. It converts
564 similarities between data points to joint probabilities and tries
565 to minimize the Kullback-Leibler divergence between the joint
566 probabilities of the low-dimensional embedding and the
567 high-dimensional data. t-SNE has a cost function that is not convex,
568 i.e. with different initializations we can get different results.
569  
570 It is highly recommended to use another dimensionality reduction
571 method (e.g. PCA for dense data or TruncatedSVD for sparse data)
572 to reduce the number of dimensions to a reasonable amount (e.g. 50)
573 if the number of features is very high. This will suppress some
574 noise and speed up the computation of pairwise distances between
575 samples. For more tips see Laurens van der Maaten's FAQ [2].
576  
577 Read more in the :ref:`User Guide <t_sne>`.
578  
579 Parameters
580 ----------
581 n_components : int, default=2
582 Dimension of the embedded space.
583  
584 perplexity : float, default=30.0
585 The perplexity is related to the number of nearest neighbors that
586 is used in other manifold learning algorithms. Larger datasets
587 usually require a larger perplexity. Consider selecting a value
588 between 5 and 50. Different values can result in significantly
589 different results. The perplexity must be less than the number
590 of samples.
591  
592 early_exaggeration : float, default=12.0
593 Controls how tight natural clusters in the original space are in
594 the embedded space and how much space will be between them. For
595 larger values, the space between natural clusters will be larger
596 in the embedded space. Again, the choice of this parameter is not
597 very critical. If the cost function increases during initial
598 optimization, the early exaggeration factor or the learning rate
599 might be too high.
600  
601 learning_rate : float or "auto", default="auto"
602 The learning rate for t-SNE is usually in the range [10.0, 1000.0]. If
603 the learning rate is too high, the data may look like a 'ball' with any
604 point approximately equidistant from its nearest neighbours. If the
605 learning rate is too low, most points may look compressed in a dense
606 cloud with few outliers. If the cost function gets stuck in a bad local
607 minimum increasing the learning rate may help.
608 Note that many other t-SNE implementations (bhtsne, FIt-SNE, openTSNE,
609 etc.) use a definition of learning_rate that is 4 times smaller than
610 ours. So our learning_rate=200 corresponds to learning_rate=800 in
611 those other implementations. The 'auto' option sets the learning_rate
612 to `max(N / early_exaggeration / 4, 50)` where N is the sample size,
613 following [4] and [5].
614

616 The default value changed to `"auto"`.
617  
618 max_iter : int, default=1000
619 Maximum number of iterations for the optimization. Should be at
620 least 250.
621  
622 .. versionchanged:: 1.5
623 Parameter name changed from `n_iter` to `max_iter`.
624  
625 n_iter_without_progress : int, default=300
626 Maximum number of iterations without progress before we abort the
627 optimization, used after 250 initial iterations with early
628 exaggeration. Note that progress is only checked every 50 iterations so
629 this value is rounded to the next multiple of 50.
630

633  
634 min_grad_norm : float, default=1e-7
635 If the gradient norm is below this threshold, the optimization will
636 be stopped.
637  
638 metric : str or callable, default='euclidean'
639 The metric to use when calculating distance between instances in a
640 feature array. If metric is a string, it must be one of the options
641 allowed by scipy.spatial.distance.pdist for its metric parameter, or

652
